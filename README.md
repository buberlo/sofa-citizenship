# Sofa Citizenship

> Earn residency on your couch and pay fines for moving too much.

A mobile app treats your phone-on-couch stillness as proof of address in the tiny nation of Sofaia. You collect residency stamps by staying put, lose points when you wander, and can naturalize a room after long lounging streaks. If you become too mobile, the app issues a deportation notice and asks where your couch actually lives.

## Features
- Stillness sensor detects couch sessions and issues residency stamps
- Movement streaks generate fines with tiny tax invoices
- Naturalization unlocks room-specific perks after seven calm days
- Shareable deportation certificate explains why your couch is no longer home

## Stack
- Swift
- SwiftUI
- CoreMotion
- CloudKit

## Getting started
```
Open the Xcode project, select an iPhone simulator or physical device, and run the SofaCitizenship target.
```
